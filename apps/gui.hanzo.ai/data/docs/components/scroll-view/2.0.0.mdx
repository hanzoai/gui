## Installation

ScrollView is already installed in `hanzogui`, or you can install it independently:

```bash
npm install @hanzogui/scroll-view
```

## Usage

```tsx
import { ScrollView, YStack, ListItem } from 'hanzogui'

export default () => (
  <ScrollView>
    <YStack>
      <ListItem>1</ListItem>
      <ListItem>2</ListItem>
      <ListItem>3</ListItem>
      <ListItem>4</ListItem>
    </YStack>
  </ScrollView>
)
```
